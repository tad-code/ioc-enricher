Que fait cet outil ?

Un indicateur de compromission (IOC) est une valeur suspecte repérée dans des journaux ou une alerte de sécurité : une adresse IP, un nom de domaine ou une empreinte de fichier. Prise seule, cette valeur ne dit rien.

IOC Enricher interroge plusieurs sources publiques de renseignement et en tire un verdict directement exploitable : réputation, niveau de risque, score sur 100, justification de ce score et action à mener. Chaque analyse est conservée en base de données, ce qui alimente l'historique et le tableau de bord.

Chaque bouton lance une analyse réelle : le rapport s'affiche immédiatement.

Comment ça marche

1. Détection du type L'indicateur est analysé par expressions régulières : adresse IP (v4/v6), nom de domaine, empreinte MD5 / SHA1 / SHA256. Les IOC neutralisés des rapports (hxxp, [.]) sont remis en forme automatiquement.
2. Enrichissement La source adaptée au type est interrogée : ip-api.com pour une IP, RDAP et le DNS Google pour un domaine, CIRCL hashlookup pour une empreinte. Une adresse privée est reconnue localement — inutile d'interroger Internet à son sujet.
3. Notation du risque Chaque signal observé ajoute des points à un score de 0 à 100 (proxy/Tor +35, hébergement +25, absence de SPF/DMARC, domaine très récent…). Chaque point est expliqué en français dans le rapport.
4. Restitution et mémoire Verdict et action à mener, puis enregistrement en base de données : les analyses passées restent consultables dans l'historique, le tableau de bord et l'export CSV.

Sources interrogées et accès programmé

ip-api.com — géolocalisation, proxy/VPN, hébergeur rdap.org — enregistrement d'un domaine dns.google — SPF, DMARC, MX (DNS-over-HTTPS) hashlookup.circl.lu — empreintes connues Python ipaddress — portée des adresses IP

Le moteur est aussi utilisable sans interface : GET /api/analyze?ioc=8.8.8.8&save=0 renvoie le rapport en JSON ; GET /export.csv exporte l'historique complet au format tableur. Voir la documentation de l'API.
