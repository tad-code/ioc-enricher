API JSON — utiliser le moteur depuis un autre outil

Le moteur d'enrichissement est aussi exposé en JSON : un script, un tableur ou un futur outil de supervision peut l'appeler sans passer par cette page.

RouteRôleExemple
GET /api/analyze Analyse un IOC et renvoie le rapport en JSON
(save=0 pour ne pas enregistrer)		 /api/analyze?ioc=8.8.8.8&save=0
GET /api/history Historique des analyses (1 à 100 entrées) /api/history?limit=5
GET /export.csv Export complet de l'historique (Excel / LibreOffice) /export.csv
GET /health Sonde de supervision (réponse minimale) /health
