API JSON — utiliser le moteur depuis un autre outil

Le moteur d'enrichissement est aussi exposé en JSON : un script, un tableur ou un futur outil de supervision peut l'appeler sans passer par l'interface web. Toutes ces routes renvoient du JSON (sauf l'export CSV).

RouteRôleExemple
GET /api/analyze Analyse un IOC et renvoie le rapport complet en JSON
(save=0 pour analyser sans enregistrer)		 /api/analyze?ioc=8.8.8.8&save=0
GET /api/history Historique des analyses (1 à 100 entrées) /api/history?limit=5
GET /export.csv Export complet de l'historique, ouvrable dans Excel / LibreOffice /export.csv
GET /health Sonde de supervision (réponse minimale, sans information de configuration) /health

Chaque élément est expliqué par l'API elle-même. Le champ explication dit ce que l'élément signifie, et pourquoi dit ce qu'il change dans l'analyse. Un outil qui consomme cette API peut donc restituer le raisonnement complet, sans avoir à réécrire le moindre texte pédagogique.

Le vocabulaire est documenté

Les {{ compte.concepts }} termes employés par l'outil — ASN, RDAP, DMARC, Tor, IOC désamorcé, faux positif… — sont définis dans le glossaire. Les {{ compte.champs }} informations possibles et les {{ compte.signaux }} signaux de score y sont également expliqués.

Depuis une ligne de commande

N'importe quel outil capable de faire une requête HTTP peut utiliser l'API :

curl "https://ioc-enricher-delta.vercel.app/api/analyze?ioc=8.8.8.8&save=0"
python -c "import requests; print(requests.get('https://ioc-enricher-delta.vercel.app/api/analyze', params={'ioc':'8.8.8.8','save':'0'}).json())"
